# Green Technology WebXR Demo — Meta Quest 2

تجربة تعليمية WebXR لدرس **التكنولوجيا الخضراء** للصف الأول الإعدادي.

## المحطات التفاعلية
- الطاقة الشمسية
- طاقة الرياح
- إعادة التدوير
- معالجة المياه

## تشغيلها على Meta Quest 2
بعد نشر المشروع على GitHub Pages:

1. افتح رابط GitHub Pages من Meta Quest Browser.
2. اضغط **Enter VR**.
3. وجّه الـ Controller إلى إحدى المحطات.
4. اضغط **Trigger** لإظهار المعلومة.

## النشر
المشروع يحتوي على GitHub Actions workflow جاهز للنشر التلقائي على GitHub Pages من فرع `main`.
