# Green Technology WebXR Demo — Meta Quest 2

## ماذا يفعل الديمو؟
- بيئة VR تعليمية عن التكنولوجيا الخضراء.
- 4 محطات تفاعلية: الطاقة الشمسية، الرياح، إعادة التدوير، ومعالجة المياه.
- على Meta Quest 2: وجّه الـ Controller إلى المحطة واضغط Trigger.
- على الكمبيوتر: يمكن المعاينة بالماوس.

## التشغيل على Quest 2
WebXR يحتاج صفحة تعمل عبر HTTPS.

### أسرع طريقة
1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى أي استضافة HTTPS ثابتة مثل GitHub Pages أو Netlify.
3. افتح الرابط من Meta Quest Browser.
4. اضغط Enter VR.
5. استخدم Trigger لاختيار المحطات.

## ملاحظات
- يحتاج اتصال إنترنت لتحميل مكتبة A-Frame من CDN.
- لا يحتاج Unity ولا تثبيت APK في هذه النسخة.
- مصمم كنسخة Demo خفيفة لتكون مناسبة لأداء Quest 2.
